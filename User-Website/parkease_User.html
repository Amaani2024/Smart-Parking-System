🔗 Firebase + Python Backend Integration

ParkEase connects your web frontend directly to Firebase Realtime Database for real-time data, and calls a Python FastAPI backend that handles ANPR, gate control, and notifications.

  • Create booking POST /api/booking
  • Check vehicle status GET /api/vehicle/{plate}
  • Trigger gate open POST /api/gate/open
  • Get all slots GET /api/slots
  • ANPR detection feed WS /ws/anpr
# ── Python FastAPI Backend (main.py) ──

from fastapi import FastAPI
import firebase_admin
from firebase_admin import firestore

app = FastAPI()
db = firestore.client()

# POST /api/booking
@app.post("/api/booking")
async def create_booking(data: dict):
  db.collection('bookings')
    .add(data)
  return {"status": "reserved"}

# GET /api/vehicle/{plate}
@app.get("/api/vehicle/{plate}")
async def check_vehicle(plate: str):
  docs = db.collection('bookings')
    .where('plate','==',plate)
    .get()
  return docs[0].to_dict()
